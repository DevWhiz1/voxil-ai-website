Quick answer

n8n automation uses n8n, a fair-code workflow automation platform that can be self-hosted or used in the cloud. It connects apps and APIs through node-based workflows, supports custom JavaScript and Python code, and includes AI agent nodes for building LLM-powered agents with tools and memory, with no per-task pricing when self-hosted.

The short version

Automation without per-task pricing, or lock-in

n8n gives engineers the speed of a visual builder with the escape hatch of real code. Self-hosted, it keeps sensitive data on your infrastructure and avoids per-task pricing that punishes high volume.
