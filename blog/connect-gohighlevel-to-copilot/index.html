How to Connect GoHighLevel to Microsoft Copilot (3 Ways)

Want Copilot to look up contacts, check pipelines or book appointments in GoHighLevel? Here are the three ways to connect them, from the HighLevel MCP server to a no-code bridge.

Teams that live in Microsoft 365 often want Copilot to answer questions like "what’s in our pipeline this week?" or "book this lead a call" using GoHighLevel data. There’s no official GoHighLevel connector in the Copilot catalogue, but Microsoft Copilot Studio can connect to GoHighLevel in three ways. Here’s how each works and which to pick.

Option 1: Use the HighLevel MCP server

HighLevel runs an official MCP server (Model Context Protocol), which lets AI assistants work with a sub-account through four tools: list locations, search operations, describe an operation and execute it, within the scopes you approve. It uses Streamable HTTP and OAuth.

Copilot Studio can connect to existing MCP servers that use Streamable HTTP, with OAuth 2.0 authentication. In outline:

  1. In Copilot Studio, open your agent and make sure generative orchestration is on.
  2. Go to Tools → Add a tool → New tool → Model Context Protocol.
  3. Enter a server name, a clear description (for example "Look up and update contacts, opportunities and calendars in our GoHighLevel sub-account") and the HighLevel MCP server URL.
  4. Choose OAuth 2.0 authentication, create the connection and sign in to approve access for one sub-account.
  5. Add the tool to your agent and test with simple read-only questions first.
Check before you rely on it
As of October 2026, HighLevel’s MCP documentation lists client-specific endpoints for Claude, ChatGPT and other OpenAI-compatible clients, and Cursor, but not Microsoft Copilot. Test the connection and the OAuth sign-in in a sandbox sub-account. If it won’t complete, use option 2.

Option 2: Build a custom connector to the HighLevel API

This is the dependable route for a production agent. You define exactly which actions Copilot can take, such as "find contact by phone", "create opportunity" or "get free calendar slots".

  1. Create a Private Integration in GoHighLevel: in the sub-account’s settings, create a private integration, select only the scopes you need (for example contacts and calendars) and store the token securely.
  2. Describe the endpoints: write an OpenAPI definition for the HighLevel API v2 endpoints you need. Requests are authenticated with the token as a Bearer header and include HighLevel’s API version header.
  3. Create the custom connector: in Copilot Studio choose Add a tool → New tool → Custom connector, import your OpenAPI file in Power Apps and configure authentication.
  4. Add actions to your agent: give each action a plain-language description so Copilot knows when to use it.
  5. Test and restrict: confirm that writes (creating or updating records) ask for confirmation, and log what the agent does.

If you’d rather not maintain this yourself, our GoHighLevel integration service builds and documents the connector for you.

Option 3: Use a bridge for reporting and alerts

  • Power Automate: send GoHighLevel webhooks (new lead, stage change, booking) to a Power Automate flow that posts to Teams, Outlook or a SharePoint list Copilot can read.
  • n8n or Make: sync GoHighLevel data into Excel, SharePoint or a database on a schedule. See our Make and GoHighLevel guide.
  • Data connectors: some reporting tools offer read-only GoHighLevel connections for analysis in Copilot. They can’t create or change records.

Security checklist

  1. Use the narrowest scopes that do the job, and one sub-account per connection.
  2. Store tokens in a secure connection, never in prompts or documents.
  3. Require confirmation for anything that sends messages, changes deals or deletes data.
  4. Check your Power Platform data policies, which also govern MCP and custom connectors.
  5. Review activity logs regularly. Our AI agent security checklist covers this in more depth.

Which option should you choose?

Use the MCP server to experiment quickly, a custom connector for a reliable agent your team depends on, and a bridge if you only need reports or notifications. Need it built properly? Book a free call.
